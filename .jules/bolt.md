## 2025-01-24 - Robust and performant type consistency checking across lists of data frames
**Learning:** The previous implementation of type checking in `get_dataset()` used nested `map` calls and a `for` loop that only compared adjacent resources. This was $O(N \times M)$, logically flawed (missed non-adjacent inconsistencies), and crashed on multi-class objects like `POSIXct`. Using `unlist(lapply(..., names), use.names = FALSE)` and `split()` on a flattened type vector is significantly faster, more robust, and handles name mismatches or differing column orders across data frames.
**Action:** Use the `split(all_types, all_names)` pattern to identify grouped properties (like types) across lists of data frames instead of element-wise comparison. Always use `class(x)[1L]` or `vapply(..., inherits, ...)` instead of `map_chr(..., class)` for multi-class safety.
