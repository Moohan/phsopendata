## 2025-05-14 - [get_resource_sql optimization] **Learning:** Iteratively converting raw record lists to tibbles using `purrr::map` + `tibble::as_tibble` is a major bottleneck. Pre-processing the raw list to handle `NULL` values and then using `dplyr::bind_rows` is significantly faster (~7x). **Action:** Always look for ways to bulk-process raw API results before converting to data frames.
