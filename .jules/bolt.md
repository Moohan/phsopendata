## 2025-05-14 - [Vectorization of Metadata Addition] **Learning:** Iteratively calling `mutate` and parsing dates for every resource in a dataset is significantly slower than parsing once and expanding metadata with `rep` on the combined data frame. **Action:** Always combine resource data first, then add context metadata in a single vectorized pass.
## 2025-05-14 - [Robust Type Checks] **Learning:** `purrr::map_chr(df, class)` fails on columns with multiple classes like `POSIXct`. **Action:** Use `vapply(df, function(x) class(x)[1], character(1))` for robust single-class extraction during type-consistency checks.
## 2025-05-14 - [Vectorized NULL Handling] **Learning:** Mapping `as_tibble` and `NULL` replacement over lists of records is much slower than using `dplyr::bind_rows` and vectorized `is.na` replacement on the resulting data frame. **Action:** Favor bulk conversion and vectorized cleanup for API responses.
