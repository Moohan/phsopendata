## 2026-04-01 - [Vectorized Record Processing] **Learning:** Converting each list element to a tibble in a loop (e.g., via `purrr::map` + `tibble::as_tibble`) is extremely slow for large results (thousands of rows). **Action:** Use `dplyr::bind_rows()` directly on the list of records and perform targeted vectorized post-processing for `NULL` coercion only on columns that actually contained `NULL` values. This achieved a ~6x speedup in `get_resource_sql`.
