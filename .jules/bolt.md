## 2026-02-24 - Vectorized Context Addition **Learning:** Vectorizing context addition *after* combining data frames (via list_rbind) and pre-parsing dates yields a >15x speedup compared to iterative addition. **Action:** Always look for opportunities to move iterative data enrichment outside of loops/pmap and apply it to the combined dataset.
## 2026-02-24 - Base R Coercion **Learning:** Base R batch coercion via lapply is significantly faster (~30x) than dplyr::mutate(across(...)) when processing many resources in a package hot path. **Action:** Favor base R for internal data transformation loops where performance is critical.
